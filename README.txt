NDS DIGITAL LAND SURVEY WEBSITE
===============================

This package is built with plain HTML + CSS + JavaScript so it is easy to customize later and does not depend on WordPress plugins or external libraries.

FILES
-----
index.html              Main content / text / menu / phone / email
style.css               Colors, spacing, responsive design
script.js               Mobile menu + active navigation
assets/hero-surveyor.jpg
assets/about-surveyor.jpg

EASY CUSTOMIZATION
------------------
1. Open index.html in VS Code / Notepad++.
2. Search for: 01885-123456
   Replace phone number everywhere.
3. Search for: nds.survey.law@gmail.com
   Replace email everywhere.
4. Replace images in assets folder using the SAME filenames.
5. Change colors in style.css under :root.
6. Service cards are inside index.html under id="services".
7. Footer and contact details are inside id="contact".

HOW TO RUN
----------
Just double-click index.html.
No XAMPP is needed for this static version.

WORDPRESS / ELEMENTOR
---------------------
You can later rebuild the same sections in Elementor using this layout as a reference. Because each section is separated and named, copying the design is straightforward.

RESPONSIVE
----------
Desktop, tablet and mobile breakpoints are already included.
